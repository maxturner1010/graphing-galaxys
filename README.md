# graphing-galaxy-s
this projects goal is to automatically fit good mathematical functions with an appropriate amount of paramaters to data.

Originally, this project was simply a way for me to learn the basics of scientific data analysis through learning some uses of NumPy, matplotlib, htm5, and sciPY.
I read astrophysics data from a htm5 file then sanitised the data. I then used curve fit with some polynomial functions with 3,4,5 parameters and then compared them to the original data using chi2 to see which model was best before visualising it by plotting the models using matplotlib.

Since then I have added extra functionality so that the code can automatically find a good type of function with an appropriate amount of parameters to fit multiple sets of data found in the htm5 file.
